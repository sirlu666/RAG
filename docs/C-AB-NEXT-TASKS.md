## C 的第一轮网页验收

仅在 A、B 双方全部工作完成、完整交付材料就绪后执行；此前保持等待，不提前开始本轮验收：

1. 登录联调账号，确认已有真实语料、标签与文档预览；查询向量使用 BGE，模型 mock=false。
2. 从实际语料选一道有明确依据的数学问题，确认 DeepSeek 真实调用成功、流式输出和公式显示正常。
3. 点击引用与对应正文，核对标题、片段、原文件及文档版本一致。
4. 追问“第二步为什么这样变形”，核对上下文与依据；失败应作为真实联调问题记录。
5. 用缺少依据的问题检查拒答和错误提示，不能把模拟模板或无依据生成记为通过。

截图/健康检查里的“已配置”不能单独算模型调用成功；以真实请求、返回模型/用量信息及对应来源为证据。付费调用在运行条件与团队使用约定明确后进行，不在本轮发生。

# 个人知识库：创建、列表、改名、删除

本轮不改数据库结构，复用 knowledge_bases 表。保留已有用户、资料和上传接口；省略 kb_id 的历史上传仍保留原默认知识库行为。

## 本次操作与预期

打开 http://127.0.0.1:5173/ ，用自己的练习账号登录。页面在“账号与个人空间”中显示“我的知识库”。

1. 输入“高等数学”，点击“创建知识库”。预期列表立即出现新库，初始 0 份文档。
2. 再创建同名库。预期提示名称重复，不新增、不覆盖已有库。
3. 点击“改名”，把名称改为“微积分”，点击“保存修改”。刷新页面后名称应保留。
4. 另建“删除练习”空知识库，点击“删除”。先取消确认，库应仍在；再删除并确认，库应消失。
5. 退出后登录另一个账号，列表应只显示该账号的库。可以在两个账号中分别创建“高等数学”，名称互不冲突。

含文档的知识库删除按钮不可用，后端也会拒绝删除；先在后续文档管理任务明确处理文档，不自动级联删除资料。改名不改变知识库 ID、文档或向量数据。误改名称可以再改回；空库删除后可以重建同名库，但 ID 会不同。

如果提示未载入知识库接口，需要重启后端并刷新列表。若页面连不上，先确认两项服务：后端启动脚本监听 8000；frontend 下的 npm.cmd run dev 监听 5173。不要对已运行的端口重复启动。

## 接口

所有接口要求有效会话，修改操作还要求 X-CSRF-Token；均采用已有响应信封。

| 方法与路径 | 用途 |
|---|---|
| GET /api/kbs | 当前账号列表，包含 document_count |
| POST /api/kbs | 创建，JSON name |
| GET /api/kbs/{id} | 单个库详情 |
| PATCH /api/kbs/{id} | 改名，JSON name |
| DELETE /api/kbs/{id} | 仅删除空库 |

名称去除两端空白后需为 1–64 字符；同账号同名返回 409，不同账号允许同名。访问他人库返回 403，不存在返回 404，未登录返回 401。

## Codex 学习点

前端的“不能点删除”只是提示；后端也必须检查权限和内容。知识库 ID 用于关联资料，改显示名称不会改变这些关联。

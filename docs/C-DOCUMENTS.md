# 指定知识库上传文档、查询进度与预览

本轮仅修改前端，复用 A 的文档接口和 C 的真实鉴权。不改数据库、不自动覆盖文件。当前一次上传一个文件；拖拽、批量、编辑和文档删除界面留在后续任务。

## 操作步骤

1. 打开 http://127.0.0.1:5173/ ，登录，在“我的知识库”找到自己创建的库，点击“打开资料”。没有知识库时先创建一个。
2. 在出现的资料区点击选择文件，选择之前的“数学上传练习.txt”。支持 PDF、DOCX、MD、TXT，单文件最多 50MB；实际后端配置更严格时以返回提示为准。
3. 点击“上传到此知识库”。预期出现文件传输进度；传输达到 100% 只表示发完文件，还要等服务器确认。
4. 请求受理后，列表显示排队/解析/向量化/已就绪。系统每 1.5 秒查询处理进度，完成或失败后停止自动查询；小文本处理快，可能直接看到“已就绪”。
5. 文档“已就绪”后点击“预览正文”。预期看到知识概念、例题等片段，每页最多 5 个，可翻页。这是解析正文，不是原文件的排版或最终的公式渲染。
6. 刷新页面并重新打开同一个库，文档应仍在；换到另一个库，不应混入当前库的资料。

## 常见结果与恢复

- 相同内容已存在：显示后端重复提示，不覆盖。先刷新列表确认已有文档，不反复重传。
- 同名不同内容：后端允许作为独立文档保存，原资料不会自动替换；列表可能出现相同文件名。
- 解析拒绝/失败：列表展示原因，例如内容不足 50 个字符或文件无法解析。修改本机原文件后，可用新的练习文件测试；不要删除已有资料来让测试通过。
- 网络断开/上传超时：先刷新文档列表，确认服务器是否已接收。上传不自动重试，以免产生重复记录。
- 状态查询出错：自动查询暂停，点击“刷新文档”重新开始。暂停查询或离开页面不会取消服务器已受理的解析。
- 退出登录或切换库：旧页面的上传/查询/预览请求会被取消，不将旧结果显示到新库。传输期间暂时禁用库操作，避免误切换目标。
- 本轮没有界面删除操作；若想清理练习资料，待文档删除功能提供明确确认后再处理。

## 验证与学习点

新增 7 项 Node 前端请求测试：multipart 知识库 ID、CSRF、浏览器边界、传输进度、重复错误、超时提示、取消请求，以及原 JSON 请求的 Cookie/CSRF 行为。`npm.cmd test` 执行，生产构建另用 `npm.cmd run build`。

本轮后端没有修改；后端鉴权、上传与预览此前已有集成验证，本次未重复运行整套 A/B 测试。请求测试使用替身验证前端协议，真实浏览器中的文件选择、进度和分页仍由学生按上述步骤验收。

请反馈：目标知识库名称、文件最终状态、片段数量、预览是否完整。不要发送登录 Cookie、CSRF token 或密码。

这一步需要理解：上传与解析是两件事；预览可用要以服务器报告的 ready 为准，而不是只看文件传输达到 100%。

# 图片识别文字校对

日期：2026-10-26。当前功能已实现，等待用户浏览器验收。

在私有练习库的 PNG/JPG/JPEG 资料上点击“校对识别文字”，可打开原图对照、编辑文字并备份保存。校对结果独立存于新增 document_ocr_texts 表，原图字节和文件哈希保持不变；首次打开显示当前片段合并的文字，长图可能有重复，需人工核对。最多 20 万字符，清理后正文至少 5 字。

保存复用原编辑流程的锁、备份、切片、向量替换和失败补偿。校对版本同时包含原图哈希、正文和片段编号，旧编辑页被拒绝；旧正文、片段和向量写入版本备份。重新索引使用已保存的校对文字；不同内容的新图替换成功后移除旧校对文字，失败则保留；删除资料同时删除校对记录。普通 TXT/MD 编辑行为保留。

浏览器验收：
1. 刷新页面，在私有练习库找到长方形练习图片，点击“校对识别文字”。
2. 打开原图对照，在练习文字末尾增加“校对备注：使用面积公式。”，点击“备份并保存”并确认。
3. 重新预览正文和打开校对面板，确认备注已保存；原图仍保持原样。
4. 新提问“校对备注使用什么公式”，检查新引用中能找到备注。mock 回答的数学正确性不作为验收标准。

验证：新增 7 项图片校对测试，覆盖三种图片格式、原图保留、向量更新、版本冲突、过短拒绝、重新索引、删除、新图替换、权限以及 embedding/vector/database 失败保留。与原编辑、替换及接口契约测试一起最后一轮共 33 项通过，前端构建通过（已有 MathJax 体积提示）。首轮普通 DOCX 替换出现一次 Windows 文件访问拒绝，单项复跑及随后完整相关批次均通过，未更改 DOCX 逻辑。OCR 推理仍使用模拟输出，本次不重复宣称实际 OCR 质量已自动测试。

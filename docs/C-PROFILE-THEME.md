2026-10-26：已实现；用户在验收步骤后要求“进入字体设置”，未报告异常，按约定继续下一小任务。

- 个人设置中可选择默认（原有绿色）、浅色、深色，点击“保存主题”后整页应用。
- 通过 PATCH /api/auth/me/theme 保存当前账号选择；恢复登录、重新登录时返回并应用主题。退出或登录失效时恢复默认。
- 新增 user_appearance 表，不修改已有 users/user_profiles 表；旧账号没有偏好记录时使用默认主题。保留昵称、头像及知识库资料。
- 全局及组件颜色使用主题变量，默认值保留原配色；深色同步 Element Plus 官方暗色变量。引用关键词保留黄色高亮。
- 不新增手机适配，不涉及 A 的标签生成或 B 的问答算法。

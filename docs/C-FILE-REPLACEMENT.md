# 文件新版本替换

目标：用同格式的新文件更新现有资料，确认成功前保留旧版正文与检索结果。前置条件：本机前后端运行、已登录、选中练习知识库；目标文档已经处理结束。

## 浏览器跟练

1. 刷新 http://127.0.0.1:5173/ 。在一份专门用于练习的 TXT 旁点击“替换新版本”。不要选择重要原件。
2. 等待当前版本读取完成，选择仓库中的 `docs/samples/数学资料-替换练习-v2.txt`。也可自建同格式的新文件，正文至少 100 字。
3. 点击“备份并替换”，核对确认框中的新文件名和目标资料名，再确认。取消确认时不会提交新文件。
4. 预期先显示传输进度。达到 100% 后还要等待服务器校验、解析、生成向量和保存；只有成功提示才代表完成。
5. 重新打开目标资料的正文预览，应看到“替换版本练习 V2”和“新版补充”。刷新页面后再预览，新内容应仍保留。
6. 检查资料展示名称、所属知识库及手动分类不变；电脑上的原文件仍保留。新文件在电脑上的名称不会自动成为资料展示名称，如需改名使用“名称与分类”。

## PDF／Word 独立练习

上传一份新建的文字版 PDF 或 DOCX 练习资料。在本机复制一份并添加至少一段内容，然后用“替换新版本”选择新副本。预期新增内容能在正文预览中看到，旧版备份保留。只允许相同格式替换，不能把 DOCX 直接替换为 PDF。

当前支持 PDF、DOCX、MD、TXT、PNG、JPG、JPEG，单文件上限由后端返回（当前 50MB）。扫描 PDF 和单张图片都受已有 OCR 配置与依赖约束；未具备识别条件时应报错并保留旧版，不视为完成图片问答。

## 常见错误与恢复

- 新文件内容与当前版本完全相同：提示无需替换，不制造重复索引与备份。
- 内容过短、格式不匹配、文件损坏或加密：拒绝更新，旧正文与索引保留。修正新文件后再选择。
- 登录过期、资料正在处理、系统正在入库或版本冲突：重新登录或等待处理完成，再重新读取版本信息、选择文件并核对。
- 连接断开或超时：不代表服务器没有保存。先重新读取版本信息、关闭面板并预览核对结果；不自动重试。重新读取会清空本页所选文件，需要再次选择。
- 旧版备份位于 `.tmp/c-demo/uploads/.versions/<文档ID>/<版本目录>/`，每版保留原文件与 index.json。普通失败使用与正文编辑相同的恢复机制；断电等跨存储故障仍可能需要人工恢复。
- 如需恢复旧版，可选择备份中的同格式原文件再次替换，经确认后作为一个新版本保存，不直接覆盖数据库或向量库。删除资料时会按确认框说明清理旧版备份。
- 文档编号保持不变，但切片 ID 会更新；旧历史对话保留，旧引用定位可能失效，新提问使用新正文。
- 自动知识标签因内容改变而清空，需重新生成；手动分类保留。

新增 GET/POST /api/docs/{id}/replacement。前者读取最新内容版本，后者使用 multipart 文件、version、登录 Cookie 和 CSRF，独立于旧 overwrite 上传路径。先解析和生成新向量，再备份并更新，避免先删旧索引。

- 个人设置提供默认、宋体、楷体，选择时展示样例；点击保存后整页应用。

浏览器验收：
1. 刷新 http://127.0.0.1:5173/，登录并展开“个人设置”。
2. 选择楷体查看预览，点击“保存字体”，检查页面文字、输入框、对话及引用正文。
3. 刷新，再退出并重新登录，确认仍为楷体；退出期间恢复默认。
4. 保存宋体，再恢复默认；确认主题选择仍保留，公式显示正常。

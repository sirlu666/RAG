# 02 · 开发流程与里程碑（v2.1 · 三人组 · 10 周）

> 总原则：**先纵向打通最窄的端到端链路，再横向加宽**。
> 反例：三人各写各的，第 8 周才联调。
> v2.1 已按 `06-范围基线.md` 移除 OCR、相似题、标签、个性化、匿名态、反馈的全部排期。

## 0. 阶段总览

| 阶段 | 周次 | 主题 | 一句话目标 | 里程碑 |
|---|---|---|---|---|
| **P0** | W1 | 契约 + 环境 + **语料验收** | 三个人对同一份契约达成一致，且语料确定能用 | 语料达标；CI 绿；mock 能跑通对话页 |
| **P1** | W2–W3 | 无登录 MVP（开发期） | md/docx → 提问 → 有引用地回答 | 端到端 Demo，三人环境都能复现 |
| **P2** | W4–W6 | 能力补齐 | 真实 PDF、混合召回、登录、可运营 | 真实教材入库；越权测试通过；容器能起 |
| **P3** | W7–W8 | 评估与打磨 | 有指标、有溯源、能录 Demo | 评估报告 v1；Demo 一次不 NG |
| **P4** | W9 | **缓冲** | 只修 bug、只做压测与回归 | 全链路回归 3 遍通过 |
| **P5** | W10 | 交付 | 文档、PPT、录屏、预答辩 | 交付物齐全 |

**Gate 是决策点，不是闸门**：三选一 —— 通过 / 降级（砍哪项已写死）/ 延期（吃 W9 缓冲）。不允许"带着坑进下一阶段"，也不允许"造假 DoD"。

## 1. P0 · W1 契约、环境、语料

| 天 | 全员 | A | B | C |

**Gate 0（硬指标，缺一不可）**
1. 任选 1 本目标教材：解析后 ≥ 5 万汉字、抽 5 页人工确认无乱码/无错序、能识别 ≥ 30 个"例 N"。

3. CI 绿（ruff + pytest + vue-tsc + build）。
4. 对话页能用 mock 流式打印。

不达标 → 换语料/换学科范围，**不许进 P1**。

## 2. P1 · W2–W3 无登录 MVP（仅开发期）

**范围**：只支持 md/docx/txt；不登录、不建库（固定 `public`）；纯向量召回；UI 不美化。
**注意**：P1 不做登录只是为了缩短链路，**产品不提供访客入口**（访客态已按 06 砍掉）。登录在 W4 补上后，MVP 立即收敛为"必须登录"。

| 周 | A | B | C | 集成点 |
|---|---|---|---|---|
| W2 | 解析器 + 结构化识别 + 切片器 v1 + 批量入库脚本 | embed → chroma query → prompt → DeepSeek（先非流式） | 上传组件 + 文档列表 + 会话页（无登录） | 周五：50 个 chunk 能被检索到 |
| W3 | 去重（content_hash）+ 删除重建 | 接 SSE + citation 事件 + 拒答阈值 | 流式渲染 + 引用卡片 + 打字机 | 周五：**端到端 Demo**（上传 md → 提问 → 有引用） |

**Gate 1**
1. 端到端可跑（开发期不校验登录）：上传 → 入库 → 提问 → 流式回答 + 引用。
2. 20 个问题中 ≥ 14 个 Top-5 命中正确片段（人工判定，用固定问题表）。
3. 三人机器都能复现（按 README 两条命令）。
4. 首 token < 3s，完整回答 < 20s。

## 3. P2 · W4–W6 能力补齐

| 周 | 重点 | A | B | C |
|---|---|---|---|---|
| W4 | 真实 PDF | 文本层解析、页眉页脚清洗、页码映射、无文本层拒收（`rejected`） | 混合召回（BM25 + 向量 + RRF） | 登录/JWT + 路由守卫 + 知识库列表/新建/删除 |
| W5 | 检索质量 | 入库任务状态机 + 进度 + 单写入者 | Rerank 接入 + 置信度阈值 + 多轮上下文（3 轮，不改写） | 文档预览页（分页看 chunk）+ 删除/重建索引 |
| W6 | 可运营 + 部署演练 | 一致性校验脚本 + `rebuild_index.py` | 缓存重复 query + 性能压测（5 并发） | 越权测试联调 + **首次完整 Docker build** |

**Gate 2**
1. 真实教材入库 ≥ 300 chunk，Top-5 命中率 ≥ 0.8（50 题）。
2. 越权测试通过：用户 A 传 B 的 kb_id → 403。
3. 登录 → 建库 → 上传 → 提问 → 看历史，全流程无断点。
4. 容器能起，SSE 逐字输出（不是攒包）。

## 9. 部署流程（W6 演练、W9 复跑）

```bash
cp .env.example .env && vim .env       # 填 key
cd frontend && pnpm install && pnpm build   # compose 挂载 dist，必须先 build
cd .. && docker compose -f deploy/docker-compose.yml up -d --build
curl localhost/api/health
```

- 数据卷：`./data/chroma`、`./data/app.db`、`./data/uploads`（备份这三个就够）。
- Nginx：`/api` 反代且 `proxy_buffering off`，否则 SSE 变一次性返回。
- 现场兜底：本地 `uvicorn + vite preview`，Docker 作为备份。

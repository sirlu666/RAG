# 引用关键词高亮与查看原文件

本课在已有“查看对应正文”基础上继续：引用片段会从当前问题提取最多 8 个关键词并高亮；找到仍然有效的引用片段后，登录用户可以打开或下载该文档的当前原文件。

## 浏览器验收

1. 如果后端窗口仍在运行旧代码，在该窗口按 `Ctrl+C` 正常停止，然后在新的 PowerShell 窗口启动后端：

   ```powershell
   Set-Location -LiteralPath 'D:\我的文档\文档\ChatGPT\codex学习\RAG'
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
   .\scripts\start-c-demo.ps1
   ```

   前端 5173 服务保持运行。刷新 `http://127.0.0.1:5173/` 并登录。

2. 选择一个已就绪的知识库，询问资料中确实出现的关键词，例如“解方程 x^2-3x+2=0”。展开引用。预期问题中的中文词和公式片段在引用摘要中以浅黄色标记显示；普通文字仍可正常阅读。
3. 点击“查看对应正文”。预期能定位到原解析片段，并看到“打开 PDF 原文件”或“下载原始文件”入口。
4. 点击原文件入口。PDF 通常在浏览器新标签页打开；DOCX、TXT、MD 通常由浏览器下载。文件内容应与当前资料版本一致。
5. 可选：以另一个已登录账号查看明确公开的知识库引用，应能访问原文件；游客没有引用和原文件入口。私有库的其他账号仍应收到无权访问提示。

## 如何理解高亮与版本

高亮是展示辅助，不代表检索评分或数学正确性。页面通过 Vue 文本节点和 `<mark>` 显示匹配词，没有把引用文本拼成 HTML。

打开原文件前，前端会先用引用的 `chunk_id` 在当前解析正文中定位。若资料已替换且该片段不存在，会提示引用可能已更新，不显示原文件入口。原文件接口提供的是文档当前版本；旧历史引用不会自动映射到新版内容。

后端从数据库已授权文档记录读取存储路径，不接收客户端文件路径。必须登录，并且只允许所有者或当前公开知识库的登录读者；游客不能访问。PDF 使用浏览器内联查看，其余格式作为附件返回，避免把 TXT/Markdown 当成可执行网页。

## 常见错误与恢复

- 点原文件后 404：后端可能尚未重启或文档文件已不可用。确认后端窗口已启动新代码、健康检查正常，再刷新页面。
- 401：重新登录后再打开引用。
- 403：确认当前账号是否为所有者，或知识库是否仍公开；公开状态改变后刷新页面。
- 提示引用片段已更新：这是旧问答对应的切片不再存在。重新提问以生成当前版本引用，不要将旧引用当作新版定位。
- 下载了文件但没有新标签页预览：这是 DOCX/TXT/MD 的预期行为；在浏览器下载列表打开文件。

### A-02 交付真实自动标签及消费约定

目标：A 生成的标签可以被 B 检索路由与 C 展示筛选消费。

标签约定（沿用 C 现有消费结构）：

```text
documents.tags_json: JSON object
  knowledge_points: string[]，最多6项，每项最多40字符
  question_types: string[]，最多5项，每项最多24字符
  difficulty: "基础" | "进阶" | "困难"
documents.difficulty: 与标签JSON中的有效难度一致；未标注可为空

GET /api/docs 的追加字段：
  knowledge_points: string[]，未标注为[]
  question_types: string[]，未标注为[]

```

要求：

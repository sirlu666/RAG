# 拍照识题入口

日期：2026-10-26。入口已实现，等待浏览器验收。

私有知识库资料上传区新增“拍照识题”，使用浏览器原生文件选择与 capture="environment"。支持的手机浏览器可请求后置相机，桌面通常选择图片；具体表现由浏览器决定，不保证强制打开相机。不申请持续摄像头权限，不自动拍摄或上传。

照片采用独立生成的名称，避免多张照片都叫 image.jpg 导致同库重名；只接受 PNG/JPG/JPEG，HEIC 等需先转换。照片进入已有上传队列，用户仍须点击上传，后续沿用格式/大小校验、OCR、片段预览、引用与识别文字校对。取消选择不改变队列，上传或编辑期间入口禁用。

本次只增加前端入口，没有改变监听地址、防火墙或后端。本机仍使用 http://127.0.0.1:5173/，手机不能通过自己的 127.0.0.1 访问电脑。先在电脑验收入口和完整上传链路；手机真实相机验收需后续单独配置仅限本地局域网的访问，再在实机测试，不能据桌面选择文件宣称已通过手机实拍。

电脑验收：
1. 刷新页面，选择私有练习库，点击“拍照识题”。
2. 选择一张 PNG/JPG/JPEG 题目图片，确认队列出现“拍照-...”名称，此时尚未上传。
3. 点击上传，等待就绪，检查正文，再打开“校对识别文字”和原图。
4. 再点“拍照识题”后取消，队列应保持原样。

验证：前端构建和现有上传队列 4 项测试通过；已有 MathJax 构建体积提示。未新增低风险 UI 的实现细节测试，未进行自动浏览器或手机相机测试。

# 个人设置：头像

日期：2026-10-26。已实现，等待用户浏览器验收。

登录后展开“个人设置”，选择 PNG/JPG/JPEG 图片（不超过 2MB），先显示本机预览，再点击“保存头像”。保存时按 EXIF 纠正方向、居中裁为 256×256、去除原图元数据并转成 PNG。刷新或重新登录保留头像；“恢复默认头像”需浏览器确认，恢复昵称/用户名的首字头像。

头像内容与摘要保存在新增 user_avatars 表中，SQLite 事务更新，不创建上传目录中的用户原图副本。头像最多 2500 万像素，校验图片真实格式与扩展名；损坏、伪装、空文件、超限或保存失败均保留旧头像。昵称、登录账号、资料与历史归属保持不变。新表由启动时 create_all 增量创建，不变更既有表列，不新增依赖。

接口：GET/POST/DELETE /api/auth/me/avatar，读取仅当前账号登录后可用，修改需 Cookie 会话、CSRF 与来源校验。读取响应 image/png、Cache-Control=no-store、X-Content-Type-Options=nosniff。user.avatar_url 为带内容摘要的同源地址，查询参数不决定账号归属，其他账号不能读取该用户头像。原登录及 /me 响应增加 avatar_url，默认 null。

前端 ProfilePanel.vue 选择与保存分开，支持取消选择并释放本机预览 URL；保存期间禁用并发操作与退出，超时提示刷新核对，不自动重复提交。requestApi 新增 FormData 支持，保留 Cookie/CSRF 并让浏览器生成 multipart boundary，原 JSON 及文档上传逻辑已回归。

浏览器验收：
1. 刷新 http://127.0.0.1:5173/ 并登录，展开个人设置。
2. 选择一张小于 2MB 的图片，确认本机预览；点击保存头像。
3. 确认个人空间顶部头像立即更新。
4. 刷新、退出并重新登录，确认头像保留，昵称与原资料正常。
5. 点击恢复默认头像并确认，头像应恢复为昵称或用户名首字。

验证：真实生成的 PNG/JPG/JPEG 图片经过完整接口处理，覆盖尺寸、元数据去除、持久化、新图替换、恢复默认、昵称保留、账号隔离、登录/CSRF、错误格式/损坏/超限拒绝，以及提交失败保留旧图片。与原账号和接口契约最终 32 项后端通过，9 项前端接口测试及构建通过，diff 检查通过。测试只使用 backend/tests/.pytest_data，未替用户设置或删除真实头像；未进行自动浏览器测试。首次测试的超限图片参数生成过长用例名，已给用例设置短标识，最终相关批次通过。

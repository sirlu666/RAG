# 工作空间与资料列表体验调整

用户提出：资料列表过长且不可收起，对话需要滚动很久；主页服务状态和账号设置造成杂乱。本次优先处理前端体验，暂不推进图片问答入口。

## 结果

- 侧栏提供“知识库与问答”“账号与设置”“服务状态”入口。主页移除大幅介绍、使用指南与连接/账号设置卡片，仅保留知识库及问答；服务指标、登录注册、个人设置均可在对应入口访问。
- 桌面知识库与问答采用双栏，左侧选择知识库，右侧直接提问。个人知识库列表有独立滚动范围，不随着库数量无限撑高页面。
- 资料管理通过可关闭的Element Plus抽屉打开，资料列表在抽屉内滚动，默认不会占据对话上方。未上传文件队列与编辑状态在关闭抽屉时保留，原有上传、预览、替换、删除等入口继续使用。
- 工作空间切换只隐藏视图，保留所选知识库、未发送草稿和正在运行的会话组件；退出登录时仍按原逻辑卸载个人内容。登录成功后返回知识库与问答。
- 去掉旧的“已配置但待验收”提示，并将已有资料库的对话空态改为可直接提问的提示。

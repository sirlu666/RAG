# 本机问答速度优化

用户授权优先优化响应速度。当前代码及定向测试已完成；是否已加载以本机 `nginx-restart-20261028/restart-status.json` 和下述实测证据为准，不能仅凭代码修改声称提速已生效。

## 改动

- 受控联调启动器默认关闭DeepSeek thinking，保留原模型、4096输出上限、0自动重试和累计100次/1美元保护。回答要求最短完整步骤，不重复公式、不默认并列多种解法。复杂数学题可能损失推理质量，这是速度优先的取舍。
- 向量/BM25仍各召回20条并按原RRF排序；只对前16个候选进行本地重排（至少保留所需Top-N数量），最终最多5个资料片段。拒答阈值0.62不变。截断重排池可能损失深位候选，需本机正负例检查。
- 联调CrossEncoder重排输入限制512个token，只影响评分输入，传给生成模型的入选资料正文不因此裁短。保持CPU批量2，按长度分批减少padding，串行本地重排以降低并发内存峰值。
- 缓存最多256个精确“问题+片段正文”评分，恢复原候选顺序；正文或问题改变即重新评分。不缓存用户答案或文档权限，候选和来源每次仍回表，避免删除/替换后返回旧资料。
- 入选上下文只合并空白差异的完全重复正文，保留首个实际来源及其引用定位，不做语义相似内容的强行合并。
- SSE增加检索、重排、生成及从请求流程开始到首段正文的分阶段耗时，方便定位剩余瓶颈。first_token_ms仍保留原“模型请求到首正文”口径，不混为同一个计时起点。

# 06 · 范围基线（v2.1 · 非目标全部砍掉）

> **本文件是范围的唯一准据。** 与 00–04 冲突时以本文件为准。
> 生效日期：2026-10-19。原则：**不服务于四个目标的功能，不写代码、不进接口、不占排期**。

## 1. 判据

一句话检验：**删掉这个功能，四个目标的哪一项指标会下降？** 答不出来 → 砍。

四个目标是：
1. 有据可查（引用 + 来源 + 页码）
2. 答得对（Recall@5、正确率）
3. 数学友好（LaTeX 全链路）
4. 可运营（自建库、增量更新、删干净）

## 2. 砍掉的清单（共 9 项）

| # | 砍掉的功能 | 原本归属 | 省下 | 为什么砍 |
|---|---|---|---|---|
| 1 | **拍照提问 / 图片上传 / OCR 全链路**（扫描件、公式识别、PaddleOCR、MinerU、`/chat/ocr`、`image_url` 字段） | A/C | ~35h | 不影响四个目标的任一指标；公式 OCR 准确率不可控，识别错反而污染答案；成本最高、风险最大 |
| 2 | **相似题推荐** + `/chat/similar` | B | 6h | 教学增值功能，与"答得对"无关；没有它不影响任何指标 |
| 3 | **自动打标签**（知识点/题型/难度）+ `kp_ids` / `difficulty` 元数据 | A | 12h | 标签只服务于"按标签筛选"，而筛选本身不是目标 |
| 4 | **个性化**（头像/昵称/主题色/字号）+ `PATCH /auth/me` | C | 14h | 纯装饰；答辩不加分，改样式还会引入响应式问题 |
| 5 | **未登录提问 + 匿名限流** | B/C | 8h+ | 可运营的最低要求是"有账号"；匿名态会让每个页面多一套分支，限流在校园 NAT 下还会误伤 |
| 6 | **点赞点踩反馈** + `feedback` 表 | C | 4h | 没有消费方（不做训练、不做排序），收了数据也没人用 |
| 7 | **多轮指代消解 / LLM query 改写** | B | 10h | 保留"最近 3 轮上下文直接拼进 prompt"（8h），砍掉改写模型（10h） |
| 8 | 微调（SFT/LoRA）、Agent 工具链、多模态生成、移动端 App | — | — | 原非目标，维持 |
| 9 | 教师端 / 班级 / 权限矩阵 / 收藏夹 | — | — | 原非目标，且会把单用户模型变成多租户模型 |

**连带删除物（不改会留下死代码）**

- `messages.image_url` 字段、`feedback` 表、`ChunkMetadata.kp_ids` / `difficulty` / `grade`

- `00` 原 §3 里的 OCR / 打标签 / 个性化 / 相似题行；`02` 原 W5 的 OCR 周；`03` 的 A9/A10/B10/C8/C10 任务

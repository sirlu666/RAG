# 手机局域网访问与拍照验收

日期：2026-10-26。局域网入口已启动，手机连通和真实拍照待用户验收。

本机 WLAN 当前 IPv4 为 10.34.90.55；手机连接同一可信 Wi-Fi 后打开 http://10.34.90.55:5173/。此地址可能随网络变化，请重新检查。手机自己的 127.0.0.1 不是电脑。登录状态按访问主机隔离，手机需正常登录自己的已有账号，不需要重新注册。

启动方式（保留原来的本机前端和后端）：

```powershell
Set-Location -LiteralPath 'D:\我的文档\文档\ChatGPT\codex学习\RAG'
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\scripts\start-c-lan.ps1 -Address 10.34.90.55
```

脚本仅接受已启用物理网卡上的 IPv4，拒绝通配地址和 VPN 网卡地址。单独启动一个前端，只绑定给定网卡地址，5173 端口固定；退出时恢复进程环境，不改 .env。停止该进程即关闭局域网入口，原 127.0.0.1 前端仍可使用。没有创建公网隧道、改路由器端口映射、防火墙规则或网络类别。

代理保留 Host（changeOrigin=false），后端可验证同源 Origin，CSRF 令牌及 Cookie 权限检查继续生效；没有扩展 CORS 或跳过来源检查。图片队列/照片名称改用 newUploadId：优先 randomUUID，局域网 HTTP 缺失该方法时用 getRandomValues，避免手机选择照片时报错；这些 ID 只用于队列与文件名，不用于认证。

手机验收：先打开首页并登录，选择私有练习库；再点“拍照识题”，拍一张清晰短题照片，确认加入队列后点击上传，等待就绪，核对正文、原图与校对入口。部分浏览器可能只提供图库选择，需如实记录，不能算作相机调用已验收。此入口使用原生文件捕获，不依赖 getUserMedia。

如果手机打不开：记录浏览器错误，确认手机与电脑的 Wi-Fi。当前 WLAN 被 Windows 标记为 Public；防火墙或 Wi-Fi 客户端隔离可能阻挡连接。本阶段尚未放行防火墙，也不能根据电脑自访成功宣称手机可达；后续按实际错误选择必要处理，不直接关闭防火墙或自动改为专用网络。局域网 HTTP 仅供可信网络临时练习，尚未实现 HTTPS。

验证：前端构建及 5 项上传相关测试通过（新增覆盖 randomUUID 缺失）；本机和 WLAN 地址健康检查均 app=up。同源登录探针返回正常凭据错误 401，外站 Origin 被拒绝 403，未登录真实账号或创建用户资料。后端仍仅监听 127.0.0.1:8000。

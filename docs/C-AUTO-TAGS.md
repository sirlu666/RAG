## 功能范围

资料行分别显示自动知识点、自动题型及自动难度，与原手动分类并列。支持名称、手动分类、自动知识点、自动题型、难度及有无自动标签的 AND 组合筛选，清除筛选恢复全部资料。筛选只影响当前资料列表，不改变问答的知识库范围，不删除或修改资料。

标签来源为既有 documents.tags_json 与 documents.difficulty，不在本次调用模型或写入新标签。读取时对非法 JSON、错误结构及非字符串标签进行兼容处理，空值与重复标签过滤，数量和长度沿用原标注脚本的上限。独立 difficulty 列的有效值优先，缺失时使用 JSON 内的有效难度；未标注或没有有效标签时如实显示空态。正文编辑/替换后原规则会清空自动标签，手动分类继续保留。

GET /api/docs 增加 knowledge_points、question_types、difficulty，并补充 DocListResponse 的 OpenAPI 响应结构；仍先按登录用户和知识库权限读取资料，再序列化标签，没有新增公共标签读取接口。前端使用 Vue 文本节点/ElTag 展示，不拼接 HTML。

## 当前数据与验收

只读检查发现当前 .tmp/c-demo 共有 4 份资料，均未保存自动标签；未替用户修改或注入标签。先验收真实空态：
1. 刷新页面，进入私有练习库，检查每份资料的自动标签空态及新增筛选项。
2. 标签状态选择“未标注”，应显示该库未标注资料。
3. 选择“已有标签”或某个自动难度；若该库没有相应标注，列表应显示无匹配，而非生成假标签。
4. 点击清除筛选，原资料恢复。可将名称/手动分类与“未标注”组合筛选。
5. 当所属库已有真实标注数据时，知识点和题型选项自动来自该库列表，可组合选择并核对标签。此正向浏览器场景尚待真实标签数据；有标签的 API 与前端筛选行为已在隔离测试中验证。

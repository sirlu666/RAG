## 不得混淆的验收

- dev 哈希向量、MOCK_LLM、模拟响应只能证明链路，不能证明真实回答质量。
- 上传网络进度与解析/向量化进度分别展示。
- 仅在前端隐藏引用不能实现游客权限。
- create_all 不会自动迁移旧表，新增字段必须有可验证迁移与恢复方案。
- 保留 A/B 输入输出契约，扩展前先检查依赖和原有测试。
- API 密钥只在本机设置；未取得现成模型调用条件时明确标记阻塞，不用模板回答冒充完成。

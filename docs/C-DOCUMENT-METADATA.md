# 文档改名与分类筛选

目标：给资料设置便于识别的名称和手动分类，再用名称与分类组合筛选。前置条件：本机前后端运行，已登录，练习知识库中至少有两份资料。

## 浏览器跟练

1. 刷新 http://127.0.0.1:5173/ ，进入练习知识库。资料行应出现“名称与分类”，列表上方有名称查找框及分类下拉框。
2. 选一份已就绪的 TXT，点击“名称与分类”，改成“方程练习.txt”，分类填“代数”，点击“保存名称与分类”。保留原扩展名；表单中的名称不能与同一知识库其他资料重名。
3. 预期列表显示新名称和分类，正文仍可预览。刷新后名称与分类应保留。电脑上的原文件名、内容不变。
4. 给另一份资料设置“微积分”分类。在分类下拉框选择“代数”，应只显示相应资料；再输入“方程”，应同时满足名称和分类条件。
5. 输入一个不存在的名称，应显示没有匹配资料；点击“清除筛选”，应恢复全部列表。筛选不会删除资料，也不会改变问答使用的知识库范围。
6. 可选：开始新对话，提问与改名资料相关的问题；检索命中该资料时，新引用应显示新名称。历史对话中已保存的名称不会自动改写。模拟回答只能验证流程。

## 独立练习

- 将一份资料的分类留空保存，选择“未分类”，确认能找到它。
- 修改名称后点击“取消编辑”，应出现放弃修改确认；确认取消后服务器仍使用原名称。
- 尝试使用其他资料的名称或把 .txt 改成 .pdf，应被拒绝，原资料保留。

## 常见问题和恢复

- 改名后资料看起来消失：检查是否仍按旧名称或旧分类筛选，点击“清除筛选”。
- 同名冲突、旧页面版本冲突、请求超时：记下需要保留的输入，关闭编辑并刷新文档列表核对，再重新编辑；不自动覆盖。
- 处理中不能编辑；系统正在入库时可能提示 409，等待完成后重试。
- 分类最多 64 字符，名称最多 255 字符；保留扩展名，不使用路径和 Windows 特殊/保留文件名。
- 这是展示名称调整，不移动服务器文件，不重新调用 Embedding；名称会同步到向量元数据，并使检索名称缓存失效。普通写入失败会回退旧名称和向量元数据。
- 手动分类独立存表，保留 A 的自动知识点、题型、难度标签；编辑正文后手动分类仍保留，自动标签则需重新生成。
- 如需恢复旧名称或分类，重新打开表单输入旧值即可；不会合并或覆盖同名资料。

## 验证与 Codex 学习

教师侧：37 项相关后端测试、2 项前端筛选测试和前端构建通过。涵盖名称同步、检索缓存、权限/CSRF、冲突、写入失败恢复、正文更新后保留分类及删除分类记录。测试仅使用隔离数据。

解释这两个区别：改名为什么不需要重新生成向量？为什么筛选结果为空不代表资料被删除？

新增 GET/PATCH /api/docs/{id}/metadata；编辑器打开时单独读取最新版本，读取成功后才允许保存，不依赖缓存列表的版本字段。文档列表追加 category 与 metadata_version。新增手动分类表，通过 create_all 创建，不修改旧文档表。接口契约已同步。

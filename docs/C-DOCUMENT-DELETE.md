# 删除一份练习资料

目标：理解确认删除的范围，验证取消无修改、确认后文档与索引清理。前置条件：前后端已运行，登录后选中练习知识库。

## 浏览器跟练

1. 刷新 http://127.0.0.1:5173/ 。为删除练习新建一份 TXT（至少 100 字，使用独有内容），上传并等待“已就绪”。请保留电脑上的原文件，不用重要资料练习。
2. 点击该资料旁的“删除”。应出现包含文件名的确认框，说明服务器文件、正文片段和检索索引会被删除，历史回答保留但对应正文可能无法打开。
3. 先点击“取消”。预期资料仍在列表，正文仍可预览；此时没有发送删除请求。
4. 再点击“删除”，仔细核对文件名后确认。预期出现删除成功提示，目标从列表消失，已打开的目标预览关闭，知识库文档数随之更新。
5. 刷新页面，确认目标没有重新出现，其他资料仍可预览；电脑上的原始 TXT 仍存在。

## 常见错误与恢复

- 正在处理的文档：删除按钮暂不可用。等待完成或处理失败后再试。后端也会拒绝处理中删除。
- 409：系统正在入库，等待其他处理任务完成，刷新后重试。当前部署是单进程，采用共享入库锁。
- 401：重新登录，再核对列表；403：检查是否登录了资料所属账号。
- 网络超时或报错：先刷新列表确认是否已经删除，不连续重复点击。
- 删除无法直接撤销。若误删自己的练习文件，可用本机保留的原文件重新上传，会生成新的文档 ID；旧历史引用不会自动改绑。

历史回答中的引用文本属于保存的对话内容，删除文档不会抹去历史。删除后“查看对应正文”可能显示不存在，这是预期行为。

## 独立练习与 Codex 学习

用第二份练习资料重复“取消—预览—确认—刷新”，并解释：为什么前端禁止点击后，后端仍要检查权限和处理状态？

教师验证：26 项相关后端测试通过（含原文档接口、知识库、真实账号删除）；前端构建通过。测试只使用 backend/tests/.pytest_data，未删除用户演示资料。浏览器确认框与列表效果需学生验收。

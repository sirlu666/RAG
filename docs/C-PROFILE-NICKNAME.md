# 个人设置：昵称

日期：2026-10-26。已实现，等待用户浏览器验收。

登录后在“账号与个人空间”展开“个人设置”，输入最多 30 字符的昵称并保存。个人空间名称和字母头像立即更新；刷新与退出后重新登录仍保留。留空保存恢复显示登录用户名。昵称允许重名，使用 Vue 文本节点显示；登录用户名、密码、账号编号、资料和对话归属不变。

后端新增 user_profiles 表，不修改既有 users 表结构；旧账号无需初始化个人资料，读取时昵称默认为空。GET /api/auth/me、注册和登录响应增加 user.nickname；PATCH /api/auth/me 只修改当前登录账号，校验 CSRF 与来源，拒绝额外 user_id 等字段。昵称去首尾空格，拒绝超长、换行与控制字符；响应 Cache-Control=no-store。

前端 ProfilePanel.vue 复用现有账号状态；保存期间禁用退出，重复保存被阻止，页面卸载取消请求。超时提示刷新核对，不自动重试。此课仅完成昵称，头像上传、主题和字体持久化后续单独实现。

浏览器验收：
1. 刷新 http://127.0.0.1:5173/ 并登录。
2. 展开个人设置，输入“数学学习者”，点击保存昵称。
3. 确认个人空间名称立即改变，登录用户名仍显示原值。
4. 刷新页面，再退出并用原用户名登录，确认昵称仍在、原资料仍可见。
5. 清空昵称并保存，确认恢复显示用户名。

验证：昵称持久化/清空、登录身份保持、输入校验、CSRF/登录要求与账号隔离测试已补齐；与原账号、旧库迁移及接口契约共 25 项通过，前端构建及 diff 检查通过。测试仅使用 backend/tests/.pytest_data，不替用户修改真实昵称。新表由后端启动时 create_all 增量创建，无 .env 修改、依赖安装、Git 提交或推送。

2026-10-26：用户在昵称验收步骤后回复“下一步”，按合作约定记为验收通过并推进头像设置。

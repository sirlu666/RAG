# 会话历史：刷新后重新打开和追问

新增当前账号历史列表、消息读取、改名和删除接口。复用已有 conversations/messages，仅创建一个 message_states 附加表记录新回答状态，不覆盖旧消息或修改原表列。

## 启用与操作

本次教师已重启自己此前启动的本机后端，前端刷新即可。以后自行启用这些后端改动时：在运行后端的 PowerShell 按 Ctrl+C，等出现 PS 提示符，在 RAG 根目录运行 `.\scripts\start-c-demo.ps1`。

1. 打开 http://127.0.0.1:5173/ ，登录，选择之前提问过的知识库，点击“打开资料”。
2. 在问答区找到“此知识库的对话历史”，点击一条标题。预期问题、回答、公式和引用恢复显示。
3. 再刷新页面，重新选择知识库、点击同一标题，历史应仍可打开。当前不会自动选择上一次对话，需显式点击。
4. 打开历史后继续提问，预期新问题加入同一会话。完成后再次打开该历史，检查新问题已保存。
5. 点“改名”，输入“我的方程练习”。刷新历史后新标题应保留。
6. 为删除练习点“新对话”，发送一题，等生成结束，再删除这条测试对话。确认框先取消，历史应仍存在；再次删除并确认后，该对话及其消息永久删除。其他历史、知识库与文档应保留。

不要拿需要保留的历史试删。“新对话”只切换到空白展示，不删除任何已存消息。误改标题可再改回；删除历史不可直接撤销。

## 状态与分页

- 每页列 20 个会话，可点“更多历史”。按当前知识库精确过滤，标题改名不改变会话 ID。
- 打开对话先读最近 50 条消息；还有内容时，可点“加载更早消息”。消息用游标向前取，新增消息不会推移旧分页；历史分页边界两端的问答会重新配对。
- 不把缺回答的历史问题伪装成完整答案；旧记录缺少完成状态时标“旧历史记录”。新记录区分完成、失败和中断，原模拟回答保留模拟标签。
- 无依据回答不把引用作为解答证明。done 事件的修正后全文与引用会写入数据库，刷新前后保持一致。
- 单进程服务内禁止同一会话同时生成两次，并拒绝删除正在生成的会话。当前页面生成期间也禁用历史切换/改名/删除；停止后若服务器仍未清理完，可稍后再刷新。
- 切换知识库或退出账号时取消旧请求，不让迟到的历史覆盖新页面。

## API

所有接口只处理当前账号的数据。修改操作继续要求 Cookie + X-CSRF-Token。

| 方法与路径 | 行为 |
|---|---|
| GET /api/conversations?kb_id=&page=1&size=20 | 分页列表，返回 items/total/page/size |
| GET /api/conversations/{id}/messages?size=50&before_id= | 返回 conversation/items/has_more/next_before_id，items 按时间正序 |
| PATCH /api/conversations/{id} | JSON title，去空白后 1–120 字符 |
| DELETE /api/conversations/{id} | 事务内删除该会话附加状态、消息与会话，保留资料 |

不存在返回 404，其他账号访问返回 403，未登录 401，修改缺 CSRF 返回 403，生成中的删除或重复生成返回 409。失效消息游标返回 400，重新打开即可。

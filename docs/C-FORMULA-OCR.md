# 单条印刷公式截图识别与校对

日期：2026-10-26。本次小任务已实现，教师真实推理与隔离链路检查通过，等待用户浏览器验收。

## 使用

1. 在私有练习库打开一张已就绪图片的“校对识别文字”。
2. 点击“识别公式截图”，选择 PNG/JPG/JPEG 单条印刷公式截图。可用 docs/samples/公式识别练习.png，图中为 x²−3x+2=0。
3. 检查 LaTeX 建议，点击“预览公式建议”；可编辑建议。建议此时尚未入库。
4. 点击“追加到待保存正文”，按需删除原 OCR 的错误或重复公式，再点“预览文字与公式”。
5. 点击“备份并保存”并确认；重新打开正文核对，原图应保持不变。新提问可引用保存后的内容，mock 答案的正确性不作为验收标准。

本阶段仅验收清晰、独立的印刷公式截图，不能据此宣称手写、多行推导、矩阵、分式或中英文混排全都可靠。自动检测独立公式行仍依赖文字 OCR 的候选判断，会漏检；显式截图识别直接处理原截图。模型输出可能错误，始终需要人工校对。

## 本机运行

采用 RapidAI/RapidLaTeXOCR 的 ONNX 方案，图片通过本机子进程输入，不上传外部服务。独立 .venv-formula 环境与主 .venv 分开，避免其 numpy<2 要求影响主项目；相关依赖见 backend/requirements-formula.txt。公式截图在内存传输，不创建用户资料文件，识别接口不自动保存正文。

准备新环境时在仓库根目录运行（当前电脑已完成，不需重复）：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m venv .venv-formula
.\.venv-formula\Scripts\python.exe -X utf8 -m pip install -r backend/requirements-formula.txt
.\.venv\Scripts\python.exe -X utf8 scripts/prepare-formula-model.py
```

模型位于 data/models/formula-onnx，四个文件合计约 179 MB；下载脚本固定官方 v0.0.0 发布地址，使用临时文件和超时，已存在文件保留。请求期间不会下载模型。启动脚本 start-c-demo.ps1 只在进程中设置 OCR_FORMULA=rapid_latex，不修改 .env。主环境和公式环境 pip check 均通过。

识别子进程限时 120 秒，不开启可见控制台；请求最多 50MB，图片最多 2500 万像素，校验真实格式并处理 EXIF 方向。模型偏好小截图，推理前按比例缩小到宽不超过 350、高不超过 128；该缩放只影响临时推理输入，不改变原图。一次请求内串行处理公式，失败时保留普通 OCR 文字。

## 代码与权限

- POST /api/docs/{doc_id}/formula：所有者登录、CSRF、当前正文版本校验，返回 doc_id/latex/version；不写文档或索引。公共读者不能调用维护接口。
- document_text.recognize_formula 复用文档维护锁，避免与替换/删除并行。
- parsing/formula.py 调用隔离解释器；scripts/formula-worker.py 仅识别，不写资料和剪贴板。
- 校对界面复用已有 AnswerContent、MathJax 和 DOMPurify 预览，不拼接未经处理的 HTML。
- 保存复用既有正文备份、索引更新及故障保留；旧引用的版本关系仍按原规则处理。

# 数学问答：SSE、公式与引用

> 后续更新：已接入 [会话历史与继续追问](C-HISTORY.md)。本页保留初次问答练习记录；关于历史列表是否可用的说明以新课为准。

本次接入现有 B 问答接口，未改变检索、生成或存储实现。仍要求真实登录与 CSRF；模型是否模拟与账号鉴权互相独立。

## 学生验收

1. 打开 http://127.0.0.1:5173/ ，登录，找到有“数学上传练习.txt”的知识库，点击“打开资料”。
2. 在资料区下方找到“基于某知识库提问”。确认模型模式标签。当前启动脚本使用模拟模式，无需配置密钥。
3. 输入“解方程 x²−3x+2=0，并说明步骤。”，点击“发送问题”。预期出现自己的问题、回答及公式。模拟模板生成很快，可能瞬间完成；不要据此判断是否使用流式协议。
4. 展开“检索到的参考片段”，点击“查看对应正文”。预期定位到同一文档的实际片段。这里是正文定位，不是 PDF/Word 原版式预览。
5. 输入“第二步为什么这样变形？”继续提问，复用当前会话；模拟模型不具备真实追问解释能力，只验证链路。
6. 生成期间可点“停止生成”，已收到内容保留并标为部分回答。模拟模板太快时按钮可能来不及点击，自动化测试已覆盖延迟流取消。
7. 点击“新对话”开始另一段对话。切换知识库会取消旧流并清空当前页面展示，不把旧结果显示在新库。

当前历史列表还未接入：刷新或切换知识库会清空前端展示，但不会删除服务器已保存的消息。停止接收不能保证撤销服务器已经处理或保存的消息，不会自动重试提问。

## 模拟与真实的边界

B 的模拟实现返回固定公式和模板，并不根据本题求根。模板可能与题目无关，当前不作数学正确性验收。真实模型密钥、真实语义向量及检索阈值需要在后续阶段配置和验证，不把开发哈希向量当作检索质量证明。

资料不足或模型声明无依据时，页面显示“资料依据不足”，不把它当正常有据答案，也不展示参考片段作为证明。

## 处理与显示

- POST /api/chat/stream，JSON 含 kb_ids/question/conversation_id/stream，Cookie + X-CSRF-Token。没有自动重连，避免重复写入问题或重复调用模型。
- 解析 meta/citation/delta/done/error；支持中文多字节跨块、CRLF、注释和多行 data。缺少 done 的断流标为部分回答。
- done 中完整 answer 优先于流式拼接文本，以使用 B 修正后的引用编号。
- 120 秒无数据或总计 5 分钟超时，保留已收到内容并提示。请求失败和停止生成分别显示。
- Markdown 禁用原始 HTML，MathJax 3.2.2 以模块方式在本机生成 SVG，再经 DOMPurify 清理后显示；公式模块按需加载，首次显示可能稍慢。使用受限基础/AMS 公式包，不动态加载外部扩展。
- MathJax 版本已锁定；上游语音依赖中的 xmldom 通过 override 锁定修复版本 0.9.12。未引入外部 CDN，构建对大型公式模块有体积提示。
- 支持 $...$、$$...$$、\\(...\\)、\\[...\\]。未闭合公式在生成中先显示文字；代码块不渲染公式。
- 引用仅显示后端提供的检索片段；通过 doc_id/seq 取对应预览页，并核对 chunk_id，资料已变化时明确提示。引用高亮和原文件浏览在后续任务处理。

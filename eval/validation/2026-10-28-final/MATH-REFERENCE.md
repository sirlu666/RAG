# 复核用数学参考

这是评审参考，不加入检索知识库、不提供给被评估模型。方程、驻点、端点值、求导、定积分及基本极限已用本机已有 SymPy 独立计算核对；证明题仍需逐步检查逻辑，不能以数值抽样代替证明。

| 题号 | 结论和必要条件 |
|---|---|
| h001 | 两根为 2、3，代入方程均为 0。 |
| h002 | x=2、y=1，满足和为 3、差为 1。 |
| h003 | f(x)=(x+1)^2−1；在 (−∞,−1] 严格递减、[−1,+∞) 严格递增。对 x1<x2，差的符号由 x1+x2+2 决定。 |
| h004 | 定义域和值域均为实数除去 0；任意非零 y 的原像为 x=1/y。 |
| h005 | f'(x)=3(x−1)(x+1)，−1 处极大值 2，1 处极小值 −2。 |
| h006 | 驻点 0、±1；端点 ±2。对应函数值为 0、−1、8；最大值 8 在 ±2 处取得，最小值 −1 在 ±1 处取得。 |
| h007 | 设 n>=1 为整数，a_n=(1+1/n)^n。二项式展开为 a_n=Σ(k=0..n) [1/k!·Π(j=0..k−1)(1−j/n)]。当 n 增加，每个已有非负项不减，另增一个正项，故严格递增。各乘积不大于 1，且 Σ(k=0..n)1/k!<3（k>=2 时 k!>=2^(k−1)，有限几何级数给出严格上界）。故有上界，并由单调有界准则收敛。只写“逐项比较可证”不足以展示完整证明。 |
| h008 | p 级数，p=2>1，故收敛；可用积分比较。无需额外断言其和为 π²/6。 |
| h009 | x²+1−2x=(x−1)²>=0，对所有实数 x 成立，当且仅当 x=1 取等号。 |
| h010 | n=1 成立；假设 Σ(k=1..n)k=n(n+1)/2，则再加 n+1 得 (n+1)(n+2)/2；归纳域为正整数。 |
| h011 | 常数 −1 相消；平方差公式给出 (x2−x1)(x1+x2+2)。x1<x2 时 x2−x1>0。两因子同时取负后乘积不变；不能声称乘积与差反号。应明确所解释的是历史中的哪条等式。 |
| h012 | 直接引用 sinx/x→1 之外，可在资料明确给出 sinx=x−x³/6+o(x³) 时，两边除以 x，得 1−x²/6+o(x²)→1。这是由引用资料的展开式推导，不应误称完全没有替代解法。 |
| h013 | lim(x→0) sinx/x=1；lim(x→∞)(1+1/x)^x=e，也可等价写为 lim(t→0)(1+t)^(1/t)=e。必须区分 lim(x→∞)(1+x)^(1/x)=1。 |
| h014 | 需要 0/0 或无穷比无穷型；相关函数在去心邻域可导、分母导数不为 0，并满足导数比极限存在等定理条件。导数比不存在不能反推原极限不存在。 |
| h018 | 基本极限值为 1。 |
| h019 | 乘积法则得 (1+x)e^x。 |
| h020 | 原函数 x²/2，在 0、1 处作差为 1/2。 |
